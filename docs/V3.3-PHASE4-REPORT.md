## 5. Architecture Decisions

### 5.1 Typed Record Hierarchy

```
EngineeringRecord (base)
      │
      ├── PRD
      ├── Requirement (REQ)
      └── NFR
```

All typed records inherit identity, provenance, authority, lifecycle, relationships, versioning, and validation from the base.

### 5.2 Registry Pattern

`harness/knowledge/registry.py` holds the typed class registry, breaking the circular import between `records.py` and `requirements.py`.

### 5.3 Stable Identity

- Record IDs: `PRD-001`, `REQ-001`, `NFR-001`
- Typed class names differ from IDs: `Requirement` vs `REQ`, `NFR` matches
- `create_new_version()` preserves `parent_record` in provenance

### 5.4 Relationships

- PRD → REQUIRES → REQ (stored in `PRD.requirements`)
- REQ → CONSTRAINED_BY → NFR (stored in `REQ.related_nfrs`)
- Relationships established in `__post_init__` for graph traversal

### 5.5 KnowledgeStore Integration

- `save()`: stores typed records as JSON with typed fields
- `get()`: dispatches to typed class if typed-specific field markers present
- `verify_integrity()`: computes hash from raw JSON (preserves typed fields)
- Base EngineeringRecord with `record_type="PRD"` stored without typed fields returned as base record

### 5.6 NFR Scope Semantics

NFR supports four scopes: `GLOBAL`, `PRD`, `REQUIREMENT`, `COMPONENT`. Global NFRs without REQ edges are valid.

## 6. Schemas

### PRD Schema

```python
@dataclass
class PRD(EngineeringRecord):
    record_type: str = "PRD"
    objective: str = ""
    scope: str = ""
    stakeholders: List[str] = field(default_factory=list)
    requirements: List[str] = field(default_factory=list)  # REQ IDs
    related_nfrs: List[str] = field(default_factory=list)  # NFR IDs
    priority: str = "medium"
```

### Requirement Schema

```python
@dataclass
class Requirement(EngineeringRecord):
    record_type: str = "REQ"
    req_type: str = REQ_TYPE_FUNCTIONAL
    priority: str = "medium"
    acceptance_criteria: List[AcceptanceCriterion] = field(default_factory=list)
    constraints: List[str] = field(default_factory=list)
    related_nfrs: List[str] = field(default_factory=list)
    parent_prd: Optional[str] = None
```

### NFR Schema

```python
@dataclass
class NFR(EngineeringRecord):
    record_type: str = "NFR"
    category: str = ""  # performance, security, etc.
    scope: str = NFR_SCOPE_GLOBAL
    metric: Optional[Dict[str, Any]] = None  # {name, operator, target, unit}
    measurement: Optional[Dict[str, Any]] = None  # {method, ...}
    qualitative: bool = False
    related_requirements: List[str] = field(default_factory=list)
    related_prds: List[str] = field(default_factory=list)
```

### AcceptanceCriterion Schema

```python
@dataclass
class AcceptanceCriterion:
    id: str  # AC-001
    description: str
    verification_method: str = ""
    status: str = "pending"
    provenance: Optional[Provenance] = None
    tags: List[str] = field(default_factory=list)
    version: int = 1
```

## 10. Traceability

Phase 4 establishes PRD → REQ → NFR traceability:

| Query | Function |
|-------|----------|
| Requirements for PRD | `find_requirements_for_prd(prd_id, requirements)` |
| NFRs for requirement | `find_nfrs_for_requirement(req_id, nfrs)` |
| Requirements constrained by NFR | `find_requirements_constrained_by_nfr(nfr_id, nfrs, requirements)` |
| PRD coverage | `compute_prd_coverage(prd, requirements, nfrs)` |
| Orphan requirements | `find_orphan_requirements(requirements, prds)` |
