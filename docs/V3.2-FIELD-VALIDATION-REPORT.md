## 0. Reproducibility statement (post-fix)

The Phase 8 reproducibility investigation classified this release as **R-B —
Reproducible After Deterministic Bug Fix**. Two real defects were confirmed,
reproduced, and corrected:

1. **`load_benchmark_tasks()` in-place, non-idempotent mutation** of the shared
   benchmark corpus — the second call in a process collapsed every task
   difficulty to 0.55, making same-process repeat runs diverge. Now builds per-call
   copies and never mutates the source.
2. **Ambiguous repetition default** — the accepted run used 5/5/5 but the
   runner/CLI defaulted to 3. Now canonicalized to a single source
   (`DEFAULT_REPETITIONS = 5` / `resolve_repetitions()`), consumed by CLI, runner,
   report generator and machine-readable results.

A clean post-fix rerun (`V3.2-FV8-20260912-reprod`, reps 5/5/5, seed 314159,
code_revision `37fb61c`, dataset_digest `569acf1dc759329d`,
