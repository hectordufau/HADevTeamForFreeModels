## 25. Known Limitations

1. **Phase 13 Observed Effect = NEUTRAL** — No positive or negative effect was established by the Phase 13 validation configuration. This is preserved as a limitation.
2. **G67-G70 undefined** — These gates do not exist in any authoritative document.
3. **Precedence divergence** — knowledge_policy.py and risk_security.py define different precedence values.
4. **artifacts/v3.3/ not committed** — Phase 13 validation artifacts exist only in the report, not in git.
5. **Outcome model is deterministic simulation** — competence is derived from actual knowledge records but the score/latency model uses bounded random bands.
6. **Cross-mode statistical pairing** relies on `EvaluationObservation.match_key()` which includes config JSON; since `knowledge_enabled`/`learning_enabled` flags differ between modes, cross-mode pairing rate is 0 by design.
7. **Knowledge provenance timestamps** differ between modes (each `_seed_knowledge` call creates fresh `Provenance` objects with `datetime.utcnow()`).
8. **Learning store benefit** is derived from deterministic strategy promotion, not from a trained model.
9. **Golden scenario step digests** include `compute_hash()` of records with `datetime.utcnow()` timestamps in provenance, so full-trace byte-for-byte determinism is limited to step types/statuses/IDs.
