**Version:** 3.3.0-draft

**Status:** DRAFT — Architecture Review APPROVED WITH REQUIRED ADJUSTMENTS (2026-09-17)

---

## 1. Overview

This plan implements V3.3 in 15 phases (Phase 0 through Phase 14), with 33 tasks (TASK-038 through TASK-070). Each task includes objective, files affected, dependencies, implementation requirements, tests, acceptance criteria, release gates, and estimated complexity.

**Task ID sequence:** Continues from V2.2's TASK-037 → V3.3 starts at TASK-038.

**Scope adjustment:** The architecture review removed Learning Quality optimization from full scope. The revised plan is smaller: 33 tasks (down from 41), ~90-120 new tests (down from 130-190), ~18-22 days (down from 25-30).

## Risk Assessment

| Risk | Severity | Mitigation |
|------|----------|------------|
| Knowledge graph complexity | Medium | Start with simple adjacency list; optimize later |
| Learning ↔ Knowledge feedback loops | Medium | Consistency checker flags contradictions |
| V3.2 regression | Low | Additive changes only; 729 tests must pass |
| ADRAutomation compatibility | Medium | Keep as shim; new code uses full ADR |
| Performance impact of knowledge retrieval | Low | Pre-filter by context; cache results |
| Knowledge record staleness | Medium | Lifecycle states; deprecation workflow |
| Scope creep into learning redesign | High | **Scope guard:** V3.3 integrates but does NOT redesign learning |
| SEC override by learning | High | SEC authority invariant enforced at governance layer |
