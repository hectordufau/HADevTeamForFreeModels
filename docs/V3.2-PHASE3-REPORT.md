# V3.2 Phase 3 Report — Decision Impact Persistence & Real Outcomes

**Date:** 2026-09-11
**Branch:** `feature/v3.2-learning-integrity`
**Base:** v3.1.0 + V3.2 Phases 1–2

## Summary

Implemented Decision Impact Integrity for V3.2: persisted DecisionImpact
provenance, on-init reload, `record_outcomes()`/`record_outcome()` disk
persistence, explicit COLD baseline recording, explicit outcome semantics
(IMPROVED/UNCHANGED/WORSENED/UNKNOWN), UNKNOWN handling that never counts as
harm, and evidence-grounded outcome provenance. Also closed the Phase 2
fallback gap identified in the task pre-check: a V3.2 experiment-scoped impact
can no longer silently bypass namespacing into shared V3.1 storage.

## Phase 2 Fallback Verification (pre-check)

**Finding:** The legacy `record()` path did allow a V3.2 experiment-scoped
impact to silently write to shared flat `artifacts/decisions_v31/` when an
`ExperimentContext` was missing — because the flat fallback was applied
whenever context was absent, with no way to distinguish a legacy V3.1 caller
from a V3.2 caller that dropped its context.

**Fix (implemented in `DecisionImpactTracker`):**
- New `_resolve_context()` fails **closed**: an impact carrying V3.2 provenance
  (validation_run_id/mode/benchmark_id/execution_id) MUST resolve to an
  `ExperimentContext`; otherwise it raises `V3IntegrationError` and never
  touches shared V3.1 storage.
- The flat V3.1 fallback now applies **only** to genuinely legacy operations
  (no `ExperimentContext` AND no V3.2 provenance on the impact).
- A tracker constructed *with* a context can never fall back, even if the
  caller omits the context on `record()` (context defaults to the tracker's).

## Changes Made

### `harness/planner/v3_integration.py`
- **`DecisionImpact`** dataclass extended with:
  - `validation_run_id, benchmark_id, mode, execution_id` (V3.2 provenance)
  - `outcome`: `IMPROVED | UNCHANGED | WORSENED | UNKNOWN` (default `UNKNOWN`)
  - `attribution_level`: `CONFIRMED | PROBABLE | POSSIBLE | NONE` (default `NONE`)
  - separate `selected_decision` / `baseline_decision` /
    `observed_outcome` / `comparative_outcome` fields (no conflation of a
    COLD↔LEARNED score comparison with causal attribution)
  - `evidence`: list of evidence references (`source`, `execution_id`,
    `evaluation`, `verification`)
  - `from_dict()` — backward-compatible reconstruction; legacy files lacking
    the new fields encode `outcome_improved` losslessly
    (True→IMPROVED, False→WORSENED, None→UNKNOWN)
  - `__post_init__()` validation (rejects invalid outcome/attribution) and
    backward-compat boolean derivation. `UNKNOWN` is never coerced to `False`.
- **`DecisionImpactTracker`**:
  - On-init reload `_load_persisted_impacts()` — a new instance reconstructs
    impacts persisted by a prior instance (disk, survives process restart).
  - `record()` persists to disk and is idempotent per `decision_id`.
  - `persist()` writes any impact (used after outcome updates).
  - `record_outcome()` — per decision, sets explicit outcome/attribution,
    observed/comparative outcome, evidence references, syncs legacy boolean,
    and persists to disk (full decision→execution→verification→evaluation→
    outcome→persisted lifecycle).
  - `get_summary()` aggregates by explicit outcome; legacy boolean aliases
    (`legacy_improvements`/`legacy_regressions`) preserved.
- **`UnifiedDecisionPipeline.record_outcomes()`** — now accepts explicit
  V3.2 outcome semantics OR legacy `outcome_improved`; persists changes back
  to disk (default), not just memory.

### `tests/unit/test_v32_decision_impact.py` (new, 30 tests)

## Outcome Lifecycle (Recorded & Persisted)

```
decision recorded → execution → verification → evaluation
→ outcome determined (IMPROVED/UNCHANGED/WORSENED/UNKNOWN)
→ DecisionImpact updated → PERSISTED to disk (survives restart)
```

## COLD Baseline

COLD-mode decisions are always recorded as `DecisionImpact` even when
`influenced_by_learning=False`, producing a counterfactual for LEARNED
comparison. Raw COLD data is stored with its real values; **no artificial 0.5
baseline is injected** (that is deferred to Phase 5).
